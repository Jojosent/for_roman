# 💖 Романтическое интерактивное приглашение на свидание

Эстетичный, интерактивный веб-сайт для приглашения любимой девушки на незабываемое свидание с вашими 28 фотографиями, динамическими анимациями, играми, выбором времени и даты, генерацией VIP-билета и передачей данных в Google Таблицы (Google Docs).

---

## ✨ Что включено:

1. **💌 Интерактивный винтажный конверт с сургучной печатью**:
   - При нажатии конверт открывается с плавной анимацией и звуковым эффектом, являя искреннее письмо.
2. **🥰 Вопрос с убегающей кнопкой «Нет»**:
   - Кнопка «Нет» уворачивается от пальца на телефоне и от мышки на ПК, выдавая милые фразы («Ой, кнопка убежала!», «Ты уверена? 🥺», «Отказы не принимаются 💕»).
   - Кнопка «Да» увеличивается и пульсирует.
   - При нажатии «Да» — праздничный фейерверк из конфетти и сердец!
3. **📸 Полароидная галерея из 28 фотографий**:
   - Ваши фотографии `photo-1.jpg` – `photo-28.jpg` оформлены в виде стильных полароидных снимков с романтическими подписями.
   - Двойной тап / сердечко ❤️ добавляет фото в «Любимые» с разлетающимися искрами.
   - Полноэкранный просмотр (Lightbox) с перелистыванием.
4. **📅 Конструктор идеального свидания**:
   - Выбор конкретной даты (настраивается в админке или свой вариант).
   - Выбор конкретного времени встречи (настраивается в админке или свой вариант).
   - Выбор формата вечера (Романтический ужин, Кофе и прогулка, Секретный сюрприз и др.).
   - Выбор кухни / вкусностей (Итальянская паста, Суши, Десерты, Бургеры и др.).
   - Поле для её любимого трека и особых пожеланий.
5. **🎫 VIP Золотой билет на свидание**:
   - Индивидуальный билет с её именем, датой, временем и программой.
   - Кнопка «Отправить в WhatsApp» / «Отправить в Telegram» с уже готовым текстом в 1 клик!
   - Кнопка «Скопировать детали».
6. **🔒 Секретная панель управления (`/admin`)**:
   - Скрыта от интерфейса (ссылки на неё на сайте нет, вход только по прямому URL `/admin`).
   - Защищена PIN-кодом (по умолчанию: `2024`, можно сменить в админке).
   - Добавление и удаление доступных дат и времени встречи.
   - Просмотр всех полученных ответов девушки.
   - Настройка имени и текстов.
   - Подключение Google Таблиц и Telegram-бота.
7. **📊 Подключение к Google Таблицам (Google Docs)**:
   - Автоматическая отправка строки со всеми её выборами прямо в вашу таблицу через Google Apps Script Webhook.

## 🚀 Как запустить локально:

```bash
# Установка зависимостей (уже выполнены)
npm install

# Запуск локального сервера разработки
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.  
Секретная админка доступна по адресу [http://localhost:3000/admin](http://localhost:3000/admin).

## 🌐 Как задеплоить на Vercel (Бесплатно за 2 минуты):

### Вариант 1: Через GitHub + Vercel (Самый удобный)
1. Создайте новый репозиторий на [GitHub](https://github.com/new).
2. Загрузите этот проект в GitHub:
   ```bash
   git init
   git add .
   git commit -m "Romantic date invitation"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```
3. Зайдите на [vercel.com](https://vercel.com) и нажмите **Add New...** → **Project**.
4. Выберите ваш репозиторий и нажмите **Deploy**.
5. Через 1 минуту Vercel выдаст вам красивую ссылку вида `https://vash-proekt.vercel.app`, которую можно отправить девушке!

### Вариант 2: Через Vercel CLI
```bash
npx vercel
```
Следуйте простым подсказкам в терминале.

## 📝 Настройка Google Таблиц (Google Docs) за 1 минуту:

1. Создайте новую таблицу на [sheets.new](https://sheets.new).
2. В верхнем меню нажмите **Расширения (Extensions)** → **Apps Script**.
3. Замените весь код на следующий:

```javascript
// Google Apps Script для автоматической записи ответов девушки в таблицу
function doGet(e) {
  return handleRequest(e);
}

function doPost(e) {
  return handleRequest(e);
}

function handleRequest(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    
    // Если таблица пустая, автоматически создаем красивые заголовки колонок
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        'Время отправки',
        'Имя',
        'Выбранная дата',
        'Время встречи',
        'Куда пойдем (Формат)',
        'Что будем кушать (Еда)',
        'Особые пожелания',
        'Любимый трек'
      ]);
      sheet.getRange(1, 1, 1, 8).setFontWeight('bold').setBackground('#ffe4e6');
    }

    var data = {};
    if (e && e.postData && e.postData.contents) {
      try {
        data = JSON.parse(e.postData.contents);
      } catch (err) {
        data = e.parameter || {};
      }
    } else if (e && e.parameter) {
      data = e.parameter;
    }

    // Добавляем новую строку со всеми выборами
    sheet.appendRow([
      new Date().toLocaleString('ru-RU'),
      data.partnerName || 'Моя прекрасная',
      data.selectedDate || '',
      data.selectedTime || '',
      data.selectedActivity || '',
      data.selectedFood || '',
      data.customNotes || '',
      data.favoriteSong || ''
    ]);

    return ContentService.createTextOutput(JSON.stringify({ status: 'success' }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ status: 'error', error: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
```

4. Справа сверху нажмите **Развернуть (Deploy)** → **Новое развертывание (New deployment)**.
5. Выберите тип (шестеренка ⚙️): **Веб-приложение (Web app)**.
6. ⚠️ **КРИТИЧЕСКИ ВАЖНО:** В пункте **Кто имеет доступ (Who has access)** выберите: **Все (Anyone)** (не «Только я»!).
7. В пункте **Запуск от имени (Execute as)** выберите: **Я (Me)**.
8. Нажмите **Развернуть (Deploy)** и скопируйте выданный **URL веб-приложения** (заканчивается на `/exec`).
9. Перейдите в `/admin` на вашем сайте (PIN: `2024`), во вкладке **Google Таблицы** вставьте этот URL и нажмите **Сохранить URL**!
10. Нажмите кнопку **⚡ Отправить тестовую запись в таблицу** — и строка сразу появится в вашей Google Таблице!
